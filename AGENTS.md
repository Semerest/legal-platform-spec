# AI bootstrap

This project uses the shared workflow from `semerest6/ai-workflow-core`.

1. Read all files in `.ai/core/`.
2. Read `.ai/PROJECT_RULES.md`.
3. Read only task-relevant specification/domain files.
4. Inspect actual repository state before claiming it is verified.

`.ai/core/**` is centrally managed. `.ai/PROJECT_RULES.md` and all business/specification material remain project-owned.
