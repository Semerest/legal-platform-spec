# Project Memory Policy

Preserve project-relevant requirements/corrections, accepted decisions, completed work, verified results/failures, important risks, unresolved questions and next step. Prefer `request -> decision -> work/result -> checks -> next step`. Do not preserve greetings, unrelated personal discussion, secrets, raw customer documents, huge logs/screenshots or hidden reasoning. Each project owns its own history. Current-state files hold current truth; logs hold chronology.
